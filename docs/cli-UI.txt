## Финальный MVP (то, что точно нужно)

1. --format compact (default)
 
Query: .tiles   |  Threshold: 60 | Total: 5 | CSS→HTML

=== CSS (3) ===
  [100] style.css:397     .tiles { display: grid; gap: 16px; ... }     << def
  [68]  style.css:402     .tiles[data-columns="1"] { ... }             >< mod
  [68]  style.css:406     .tiles[data-columns="2"] { ... }             >< mod

=== HTML (2) ===
  [88]  index.html:125    <div class="tiles" id="tiles" data-columns="1">   >> use
  [88]  private.html:115  <div class="tiles" id="tiles" data-columns="1">   >> use

=== JS (0) ===
  — none —

Технически:
Snippet: 60-80 символов (обрезаем по пробелу или на границе слова)
data-* атрибуты не обрезаем в snippet
Порог фиксированный: 60
CSS→HTML в хедере — показывает направление связей

2. --format tree

Query: .tiles  |  Findings: 5 | Connections: 4 | CSS→HTML

CSS Chain
  .tiles { display: grid; ... }                    [style.css:397] << def
   ├─ .tiles[data-columns="1"] { ... }            [style.css:402]   >< mod
   │  └─ .tiles[data-columns="2"] { ... }         [style.css:406]  >< mod
   └─ used in:

HTML
  ├─ index.html:125    <div class="tiles" id="tiles" data-columns="1">     >>use
  └─ private.html:115  <div class="tiles" id="tiles" data-columns="1">    >>use

JS 
  └— none
  
Технически:
Только направленные связи (parent → child)
Если связей нет — просто список (flat)
Отступы: 2 пробела на уровень
Символы: ├─ │ └─ └—


### 3. `--format json` (для LLM v0)

```bash
python cli.py .tiles ./project --json
```

```json
{
  "query": ".tiles",
  "summary": {"total": 5, "langs": ["css", "html"], "gaps": 0, "top_score": 100},
  "nodes": [
    {"id": 1, "file": "style.css", "line": 397, "lang": "css", "role": "definition", 
     "name": ".tiles", "score": 100, "snippet": ".tiles { display: grid; ... }"},
    {"id": 2, "file": "style.css", "line": 402, "lang": "css", "role": "modifier", 
     "name": ".tiles[data-columns=\"1\"]", "score": 68, "snippet": ".tiles[data-columns=\"1\"] { ... }"},
    {"id": 3, "file": "style.css", "line": 406, "lang": "css", "role": "modifier", 
     "name": ".tiles[data-columns=\"2\"]", "score": 68, "snippet": ".tiles[data-columns=\"2\"] { ... }"},
    {"id": 4, "file": "index.html", "line": 125, "lang": "html", "role": "usage", 
     "name": "div.tiles", "score": 88, "snippet": "<div class=\"tiles\" id=\"tiles\" data-columns=\"1\">"},
    {"id": 5, "file": "private.html", "line": 115, "lang": "html", "role": "usage", 
     "name": "div.tiles", "score": 88, "snippet": "<div class=\"tiles\" id=\"tiles\" data-columns=\"1\">"}
  ],
  "edges": [
    {"from": 1, "to": 2, "type": "inherits"},
    {"from": 2, "to": 3, "type": "inherits"},
    {"from": 1, "to": 4, "type": "used_in"},
    {"from": 1, "to": 5, "type": "used_in"}
  ]
}
```

Технически:
Минимальные поля (без insights)
ID — числовые (проще для LLM)
lang вместо type (короче, понятнее)
role — один из: definition, modifier, usage

📋 Чек-лист реализации
Для compact:
Группировка по lang (css/html/js)
Счетчик в каждой группе
Snippet (первые N символов, обрезать по слову)
Маркеры: << def, >< mod, >> use
Заголовок с метриками: Query: X | Threshold: 60 | Total: N | CSS→HTML

Для tree:
Построение графа связей (parent-child)
Только направленные ребра (от определения к использованию)
ASCII-дерево с отступами
Отдельные секции для несвязанных узлов

Для json:
Минимальная схема (без insights)
Все поля обязательные (null если нет)
edges — только если есть связи

Общее:
--threshold пока фиксированный (60)
--format без аргумента = default (compact)
--json = алиас для --format json
--tree = алиас для --format tree
